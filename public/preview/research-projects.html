01 / EEG hardware

EEG electrode attachments for Type 4 hair

3D-printed attachments developed and evaluated to address scalp-contact challenges across Afro-textured hairstyles.

Read project notes +

I worked on CAD design, resin 3D printing, experiment setup, participant testing and signal analysis. The goal was to understand whether new electrode attachment geometries could improve scalp contact while remaining practical for participants.

02 / Device prototyping

In-vitro spinal cord model

An anatomically detailed, printed-and-silicone model intended for cerebrospinal-fluid flow experiments.

Read project notes +

I worked on Fusion 360 CAD and mesh refinement, and helped combine rigid resin and silicone components. The project was awarded first place in BME and fourth overall at the 2026 UIC Engineering Expo.

03 / Signal analysis

EEG motor imagery classifier

A public-data analysis project using MNE-Python, common spatial patterns (CSP) and scikit-learn to evaluate subject-level motor-imagery decoding. This was a software analysis, not a built BCI device.
